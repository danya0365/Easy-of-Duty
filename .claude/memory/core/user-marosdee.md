Marosdee Uma (github `danya0365`, marosdee.fuzana@gmail.com) กำลังทำ **คอร์สออนไลน์สอน AI prompting**
โดยเฉพาะสไตล์ orchestration ที่ prompt เดียวขับ agent fleet ให้ทำงานกับ harness ที่วัดผลได้

- **เขียนและต้องการคำตอบเป็นภาษาไทย** คงศัพท์เทคนิคเป็นอังกฤษ (`pixel gate`, `subagent`, `determinism`, ชื่อไฟล์/ชื่อ tool) — เป็นสไตล์ที่พี่ใช้เอง
- **เทคนิคจัดและลงมือเอง**: อ่าน source, รันโปรเจคจริง, ถามเรื่อง token cost
  → **ไม่ต้องอธิบายคอนเซปต์พื้นฐาน แต่ต้องอธิบาย *กลไก*** ว่าทำงานยังไง
- **audience ของงานที่ผลิตออกไปคือคนหลายระดับ** — บางคนไม่เคยใช้ Claude Code เลย บางคนใช้ subagent อยู่แล้ว
  → ไล่จากพื้นเข้าลึก ไม่ตั้งระดับไว้ที่จุดเดียว
